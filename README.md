# dataset-snapshots

Unmodified copies of public datasets.

- `ubuntu.csv`: distro-info-data, tag debian/2026.10.12-1,
  https://salsa.debian.org/debian/distro-info-data/-/raw/debian/2026.10.12-1/ubuntu.csv. License: ISC.
- `geosphere_wien_10min_2020-2024.csv`: GeoSphere Austria, klima-v2-10min, station 105 (Wien Hohe Warte),
  parameters tl and rr, 2020-01-01 to 2024-12-31, downloaded 2026-11-03 from
  https://dataset.api.hub.geosphere.at/v1/station/historical/klima-v2-10min?parameters=tl,rr&station_ids=105&start=2020-01-01T00:00&end=2024-12-31T23:50&output_format=csv
  Data: GeoSphere Austria, CC BY 4.0, https://doi.org/10.60669/8fya-7x87
